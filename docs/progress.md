# 학습 실행 로그

> **이 문서의 역할**: 실제로 **무엇을 돌렸고 무엇이 막혔는지** 기록합니다.
> 집필 현황(체크박스)은 [course-plan.md](course-plan.md)에서 추적합니다 — 역할이 다르니 섞지 마세요.
> 여기 쌓인 실측값(에러·소요시간·GPU 비용)이 다음 주 교육자료의 입력이 됩니다.

---

## 기록 규칙

- 하루에 한 블록. 실습을 돌린 날만 씁니다(이론만 읽은 날은 생략 가능).
- **막힌 지점과 해결 방법은 반드시 남깁니다** — 그대로 해당 모듈 `labs/`의 "흔한 에러" 섹션으로 옮겨집니다.
- GPU 비용은 인스턴스 타입 × 시간으로 기록. 주간 예산 상한을 넘기면 §주간 요약에 표시합니다.
- `> ⚠️ 미검증(GPU 필요)` 배지가 달린 절차를 실행했다면, 검증 결과를 남기고 lesson에서 배지를 제거합니다.

### 블록 템플릿

```markdown
## YYYY-MM-DD (W_-M_ / 토픽 슬러그)

**환경**: 제공자 / 인스턴스 타입 / GPU / CUDA
**돌린 것**:
- (명령 또는 스크립트) → 결과

**막힌 지점**:
- 증상 → 원인 → 해결 (labs 반영 여부)

**소요**: 실습 _h / 학습 _h
**GPU 비용**: $_ (인스턴스 _h)
**미검증 배지 해제**: (모듈/절차) 또는 없음
**다음 액션**:
```
