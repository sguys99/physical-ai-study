### B2. 역참조 (절 번호를 바꿨다면 필수)

**파일 존재 검사는 이걸 못 잡습니다.** `labs/`와 `practice/`는 lesson의 **절 번호**로 링크를 겁니다. 재집필로 절이 재배치되면 조용히 끊어집니다.

- [ ] `labs/`와 `practice/*.py`가 인용한 `§N`이 새 lesson에 **실재**하는가
- [ ] 다른 모듈이 이 모듈을 가리키는 `{모듈ID} §N`도 살아 있는가
- [ ] 번호를 고쳤으면 `.py`를 고치고 `jupytext --sync`로 `.ipynb`를 맞췄는가

```bash
grep -rn "§[0-9]" <target_dir>/labs/ <target_dir>/practice/*.py
grep -rn "<모듈ID> §" course/ notes/ docs/
```

번호만 맞추고 설명, 수치, assert 값은 건드리지 않습니다.

## C5. 문장부호 (SSOT: course-plan §3.10)

- [ ] **산문에 줄표(—)가 없는가** (표 셀, 코드블록, Mermaid 라벨, frontmatter, 수식, 원문 인용은 예외)
- [ ] **산문에 가운뎃점(·)이 없는가**
- [ ] 헤딩 부제가 줄표나 콜론이 아니라 **한 구절로 합쳐졌는가** (`## 1. 배경 — 왜 배우나`가 아니라 `## 1. 왜 이걸 배우나`)
