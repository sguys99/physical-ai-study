## Z. eli5.md (SSOT: course-plan §2.1)

`lesson.md`보다 **먼저 읽는** 층이라 검사도 먼저 합니다. lint는 `lesson.md` 전용이라 이 절 전체가 육안입니다.

- [ ] `{target_dir}/eli5.md`가 존재
- [ ] **frontmatter가 없고**, 첫 줄이 `> 본문은 [lesson.md](lesson.md)입니다. 이 문서를 먼저 읽으세요.`
- [ ] 산문 **3,000~5,000자** (`lesson.md`의 티어 밴드와 무관한 독립 밴드)
- [ ] **수식 0.** `$$` 블록도 인라인 `$...$`도 없음
- [ ] **arXiv 인용 0.** 논문 번호와 URL은 `lesson.md`의 「출처」가 담당
- [ ] 영문 약어가 최소이고, 이름이 필요한 자리는 한국어를 앞세우고 영문을 괄호로 달았는가
- [ ] **그림 라벨에 영문 약어와 미정의 용어가 없는가**
- [ ] 골격 다섯 절이 §2.1 순서대로 있는가 (`이 모듈이 답하는 질문 하나`, `어떤 문제가 있었나`, `그래서 무엇을 하나`, `오늘 만날 개념 5개`, `이제 lesson.md로`)
- [ ] **그림마다 「읽는 법」 캡션 1~3문장**이 그림 바로 아래에 있는가
- [ ] 「오늘 만날 개념 5개」가 정확히 다섯 개이고 **각 세 문장**인가
- [ ] `lesson.md` 링크에 **절 번호와 절 제목이 함께** 적혀 있는가 (`§3`이 아니라 `§3 「스택 5계층」`)
- [ ] **요약이 아닌가.** `lesson.md`의 「한 장 정리」와 내용이 겹치면 실패입니다. 겹치는 문단이 하나라도 있으면 다시 씁니다
- [ ] 단순화한 자리마다 "정확히는 `lesson.md` §N 「절 제목」에서" 링크가 붙었는가

```bash

# lint의 산문 정의에서 frontmatter와 $$ 블록 항을 뺀 것인데, eli5는 둘 다 없어야 하므로 같은 값이 나옵니다
python3 - <target_dir>/eli5.md <<'PY'
import re, sys
s = open(sys.argv[1], encoding='utf-8').read()
struct = sum(len(m.group(0)) for m in re.finditer(r'```.*?```', s, re.S))
body = re.sub(r'```.*?```', '', s, flags=re.S)
struct += sum(len(l) + 1 for l in body.split('\n') if l.strip().startswith('|'))
print(f"산문 {len(s) - struct}자 / 총 {len(s)}자  (밴드 3000~5000)")
PY

# 첫 줄 안내문과 frontmatter 부재
head -1 <target_dir>/eli5.md

# 수식과 arXiv 인용은 0이어야 합니다 (출력이 비어 있으면 통과)
grep -nE '\$\$|\$[^$]+\$|arXiv|arxiv\.org' <target_dir>/eli5.md
```

- [ ] **산문에 가운뎃점(·)이 없는가**
- [ ] 헤딩 부제가 줄표나 콜론이 아니라 **한 구절로 합쳐졌는가** (`## 1. 배경 — 왜 배우나`가 아니라 `## 1. 왜 이걸 배우나`)
- [ ] 부연은 쉼표나 괄호로, 나열은 쉼표로, 두 항 대비는 `와/과`로 바뀌었는가

## C6. 독자를 데려가는 장치 (SSOT: course-plan §3.11)

2026-08-25에 신설된 규약이라 lint가 아직 아무것도 잡지 못합니다. 전부 육안입니다.

- [ ] **워크드 예제가 계산이 나오는 절마다 최소 1개** 있는가. 실제 숫자를 대입해 단계별로 손으로 따라가는 예제인가
- [ ] **계산을 `practice/*.py`로 외주하지 않았는가.** 실습 코드는 검산용이지 최초 이해용이 아닙니다
- [ ] **모든 기호를 그 자리에서 정의**했는가. 천장 함수 기호, 그리스 문자, 아래첨자가 무엇을 가리키는지 썼는가
- [ ] 기호가 셋을 넘는 수식 옆에 **기호표**가 있는가
- [ ] **「여기서 많이 헷갈립니다」 박스**가 오해가 생기기 쉬운 바로 그 자리에 있는가 (문서 끝의 「흔한 오해」와 별개입니다)
- [ ] **퀴즈가 3단 난이도인가.** 기억 확인 1~4번, 적용 5~8번, 종합 9~10번
- [ ] 퀴즈 문항이 **평서형 질문**인가 (`계산하라`가 아니라 `계산해보세요`)
- [ ] **문체가 전부 합니다체인가.** 본문, `📌` 박스, 「한 장 정리」 표, 퀴즈까지 한 목소리인가
- [ ] **자기 설명 프롬프트가 「한 장 정리」에 1개** 있는가 (덮고 말해보게 하는 능동 회상 장치)

## D. 본문 필수 요소

- [ ] **회사 스택 연결 섹션 존재** (없으면 미완성)
- [ ] 흔한 오해 3가지 이상
- [ ] 셀프 체크 퀴즈 10문항 + `<details>` 접힘 정답
- [ ] 출처에 arXiv ID, URL, 확인 날짜
- [ ] 회사 내부 구현을 추측한 문장이 없는가 → 있으면 "팀 확인 필요"로 바꾸고 `notes/questions-for-team.md`에 적립
- [ ] **본문 산문이 Tier 밴드 안** (A 15,000~21,000, B 13,000~18,000, C 12,000~17,000 문자. 초안은 중앙을 노릴 것)
- [ ] 밴드를 넘겨 덜어낸 것이 있으면 **`deep-dive.md`로 이관하고 본문에서 링크**했는가 (삭제가 아니라 이동)

> ⚠️ **위 밴드 숫자는 편의용 사본입니다.** 정본은 `scripts/lint-lesson.sh`와 `docs/course-plan.md` §4 **두 곳**이고, 이 문서와 어긋나면 **lint가 이깁니다.** 숫자를 여러 문서에 복사해둔 것이 3중 불일치를 두 번 재발시켰습니다(§9.11, §9.19).
