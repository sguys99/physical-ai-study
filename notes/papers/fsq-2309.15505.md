## ① 한 줄 요약 + 계보에서의 위치

**VQ-VAE의 학습되는 코드북(nearest-neighbor lookup + commitment/codebook/entropy loss + EMA·재초기화 등의 보조 장치)을, 인코더 출력을 채널별로 bounding(`tanh`)한 뒤 정수로 반올림하는 고정 격자로 대체한다. 보조 손실이 전혀 없는데도 코드북 사용률이 훨씬 높다.**

계보: VQ-VAE(Van Den Oord et al. 2017, arXiv:1711.00937, commitment loss + EMA 도입) → VQ-GAN(Esser 2020) → ViT-VQGAN(Yu 2021, $\ell_2$ 정규화 + 저차원 코드 매핑) → **FSQ(본 논문, 2023) — 코드북을 아예 없앰** → (로봇 쪽 분기) RT-2식 per-dim binning, LAPA/latent action 계열. 신경압축 계열의 bounded scalar quantization(Mentzer 2018, $d{=}16,L{=}5$ / Agustsson 2019, $d{=}5,L{=}5$)이 뿌리이며, 저자들 자신이 "FSQ가 압축 밖의 vision task에 쓰인 적은 없었다"고 명시.

## ② 방법 상세

**아키텍처(텍스트 다이어그램)**

```
입력 x → 인코더 → z ∈ R^d  (d < 10, typically)
                    │
                    ▼  bounding: f(z_i) = ⌊L_i/2⌋ · tanh(z_i)   (짝수 L_i는 비대칭 오프셋)
                    ▼  rounding: ẑ = round(f(z))                (STE로 그래디언트 통과)
                 ẑ ∈ C  (implied codebook, |C| = ∏ L_i, mixed-radix로 정수 인덱스 1개에 전단사)
                    │
                    ▼
                  디코더 → x̂
```

VQ와의 대비(원논문 Fig 2 표, 그대로):

| | VQ | FSQ |
|---|---|---|
| Quantization | $\arg\min_{c\in\mathcal C}\lVert z-c\rVert$ | $\mathrm{round}(f(z))$ |
| Gradients | STE | STE |
| Aux. Losses | Commitment, codebook, entropy | **–** |
| Tricks | EMA, codebook splitting, projections… | **–** |
| Parameters | Codebook | **–** |

**학습 objective와 직관**: 재구성 손실 하나뿐이다(+ VQ 쪽에만 있던 보조 항들이 FSQ에는 없음). 핵심 직관은 "코드북이 고정돼 있으니, 인코더가 정보를 여러 격자점에 퍼뜨리지 않으면 그 자체로 복원 손실이 커진다" — **사용률을 강제하는 것이 최적화 목표가 아니라 격자의 기하 구조**라는 점이 VQ와의 근본적 차이. 파라미터 수도 이 차이를 반영한다: VQ는 코드북 $|\mathcal C|\cdot d$개(예: $|\mathcal C|{=}2^{12}, d{=}512 \to$ 2M), FSQ는 **0개**(버퍼만 있음, `nn.Parameter` 0개를 practice에서 직접 확인).

권장 레벨(원논문 Table 1, 그대로):

| Target $|\mathcal C|$ | $2^8$ | $2^{10}$ | $2^{12}$ | $2^{14}$ | $2^{16}$ |
|---|---|---|---|---|---|
| $\mathcal L$ | `[8,6,5]` | `[8,5,5,5]` | `[7,5,5,5,5]` | `[8,8,8,6,5]` | `[8,8,8,5,5,5]` |

곱이 target과 **정확히 같지 않음**(approximately match — 240/1000/4375/15360/64000). 휴리스틱은 $L_i \ge 5$.

## ③ 실험에서 중요한 표/그림 2개와 해석

**Fig 3 (VQ vs FSQ, 128×128 ImageNet, codebook size sweep)** — Reconstruction FID는 FSQ가 코드북을 키울수록 계속 개선되는 반면 VQ는 어느 지점부터 정체·악화. **코드북 사용률이 $2^{10}$을 경계로 역전**: 그 이하에서는 VQ가 우세, 그 이상에서는 FSQ가 압도(사용률이 VQ는 절벽처럼 떨어지고 FSQ는 완만히 감소). → **직접 재현**: practice `02_fsq_vs_vq_g1.py --sweep`에서 $|C|{=}240$(VQ 83.6% 우세) → $|C|{=}1000$(21.1% vs 96.8%, 거의 동률) → $|C|{=}4375$(4.5% vs 71.9%, FSQ 압도)로 축소 재현됨. **이 논문의 핵심 주장이 우리 데이터로도 성립했다.**

**MaskGIT ImageNet 256 표** — Sampling FID 4.509(VQ, usage 81%) vs 4.534(FSQ, usage **100%**), precision/recall 유사. 성능 저하 0.5~3%인데 사용률은 거의 완전. **해석**: FSQ가 "더 좋다"가 아니라 "거의 같은 성능을 훨씬 단순한 장치로 얻는다"는 것이 논문의 실제 주장이다. 이 뉘앙스를 놓치면 "FSQ가 항상 낫다"는 과장이 된다(lesson §5.5·§8이 이 공정성을 명시적으로 다룸).

## ④ 한계와 후속 연구가 공격한 지점

- **차원 $d$가 매우 작아야 한다**(typically < 10) — 표현력이 격자 해상도로 상한이 걸림. 접촉이 풍부한 조작·고주파 힘 제어처럼 연속적 정밀도가 필요한 태스크에는 근본적으로 불리할 수 있음(논문이 직접 이 한계를 검증하진 않음 — lesson worksheet ⑥ 논거 ④에서 학습자가 직접 논증하도록 설계).
- $2^{10}$ 이하의 작은 코드북에서는 **VQ가 여전히 우세** — "FSQ가 VQ의 상위호환"이 아님.
- 논문 자체가 "FSQ가 압축 밖 vision task에 쓰인 적이 없었다"고 인정 — 즉 이 논문이 처음 시도. **로봇 액션 토큰화에 쓴 사례는 논문에 없음**(회사 적용은 우리가 추정만 하는 영역).
- VQ의 보조 트릭(EMA·재초기화·entropy loss)이 실제로 도움이 되는지: practice 실측에서 이 트릭들이 **오히려 사용률을 낮췄다**(바닐라 21.1% → EMA+init 18.3%). 논문이 예상한 것과 다른 방향인데, 이는 우리 데이터(G1 관절 궤적, 저차원·저다양성)의 특성일 수 있어 일반화하기 어려움 — 후속 검증이 필요한 지점으로 기록.

## 회사 스택 관점 시사점

FSQ가 회사 L3(액션 인터페이스)에 쓰인다는 것이 마스터플랜의 명시 사항이다. 이 논문을 이미지·라벨 도메인에서 로봇 액션 도메인으로 옮길 때 최소 세 가지가 바뀐다: ① 채널이 픽셀 패치가 아니라 관절 자유도, ② 시간축이 있다(청크·프레임 단위 처리가 필요, 논문은 정지 이미지만 다룸), ③ 하위 소비자가 다음 토큰 예측기가 아니라 실시간 WBC 정책. 이 세 변환이 회사 구현에서 어떻게 됐는지는 전부 미확인.
