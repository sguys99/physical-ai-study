## W1

### W1-M1 — Physical AI 개요와 산업 지형

| 용어 | 정의 | 비유 / 메모 | 모듈 |
|---|---|---|---|
| **Physical AI** | 인터넷 규모 데이터로 학습한 지능을 물리 법칙·실시간 제약이 있는 몸에 넣는 문제 | Embodied AI와 거의 동의어지만, 파운데이션 모델·시뮬 인프라를 포함한 **스택 전체**를 가리키는 뉘앙스(NVIDIA발 산업 용어) | W1-M1 |
| **스택 5계층 (L1~L5)** | L1 하드웨어·미들웨어 / L2 전신제어 WBC / L3 액션 인터페이스 / L4 상위 지능 / L5 인지·매핑 | 계층적 제어(supervisory·cascade control)의 재발견. **위로 갈수록 느리고 똑똑, 아래로 갈수록 빠르고 반사적** | W1-M1 |
| **대역폭 분리** | 인접 계층의 동작 주파수를 한 자릿수 이상 벌려 두 루프가 서로의 동특성에 간섭하지 않게 하는 원리 | 캐스케이드 제어의 inner/outer 5~10배 규칙. 다만 여기서는 설계 선택이 아니라 **연산 예산이 강제** | W1-M1 |
| **action chunking** | 상위 모델이 한 번의 추론으로 미래 여러 스텝의 액션을 한꺼번에 뱉는 것 | **MPC의 예측 지평 $N$** — 매 스텝 $N$개를 풀어 앞의 일부만 쓰고 버리는 receding horizon과 동형. 최적화 대신 신경망 회귀. W2-M1 블록에 compounding error 관점의 상세 정의가 있다 | W1-M1 → W2-M1 → W2-M2 → W2-M4 |
| **지연 예산 / 명령 공백** | $H_{chunk} \ge f_2(T_{replan} + \tau_{infer} + \tau_{comm})$. 이를 못 채우면 하위 제어기가 쓸 명령이 없는 구간이 생김 | 청크 = 상위의 느림을 감추는 **버퍼**. 길수록 지연에 강하지만 반응성이 떨어짐 | W1-M1 → W4-M4 |
| **데이터 피라미드** | 웹 비디오 → 휴먼 비디오·모캡 → 텔레옵 시연 → 실기 RL. 위로 갈수록 양은 많고 액션 라벨은 없음 | 병목은 "데이터 부족"이 아니라 **라벨 없는 상단을 하단으로 끌어내리는 법** | W1-M1 → W2-M5 |
| **latent action** | 진짜 액션 대신 대리 액션 $z_t = E(o_t, o_{t+1})$을 학습하고, 소량 실기 데이터로 $z \to a$ 디코더만 맞추는 접근 | 라벨 없는 비디오를 쓰기 위한 우회로(LAPA·Genie 계열) | W1-M1 → W2-M5 |
| **크로스 임바디먼트** | 서로 다른 로봇 플랫폼의 데이터를 하나의 포맷으로 통합해 함께 학습하는 것 | OXE가 22종 로봇을 묶은 것이 대표. 단일 플랫폼 대규모(AgiBot World)와는 성격이 다름 | W1-M1 → W2-M3 |
| **universal token space** | 상위의 여러 입력원(VLA·VR 텔레옵·게임패드 플래너)을 하나의 공통 토큰 표현으로 받아 단일 WBC 정책에 물리는 설계 | SONIC의 핵심. **곧 L3 인터페이스 설계 문제** | W1-M1 → W3-M4 |
| **WBC 파운데이션 정책** | 대량 모캡을 스케일업해 학습한, 태스크 비특정 범용 전신 제어 정책 | SONIC = 42M 파라미터 / 700시간 모캡 / 21,000 GPU-hours | W1-M1 → W3-M4 |

### W1-M2 — 시뮬레이터 부트캠프

| 용어 | 정의 | 비유 / 메모 | 모듈 |
|---|---|---|---|
| **MJCF** | MuJoCo의 로봇·장면 기술 XML. `<option>` `<default>` `<worldbody>` `<actuator>` `<sensor>` `<keyframe>`으로 구성 | URDF의 MuJoCo판. 다른 점은 **접촉·solver 설정까지 같은 파일에 든다**는 것 — 모델과 적분기 설정이 분리돼 있지 않음 | W1-M2 |
| **`mjModel` / `mjData`** | 컴파일 결과인 상수(관성·링크·게인·solver 옵션) vs 매 스텝 변하는 상태와 중간량 | 상태공간 모델의 $(A,B,C,D)$와 $x(t)$ 분리와 같음. **MJX가 모델 1개 + 데이터 N개로 GPU 병렬을 하는 전제** | W1-M2 → W3-M1 |
| **`nq` ≠ `nv`** | 위치 좌표 수와 속도 자유도 수가 다른 현상. G1은 36 vs 35 | 자유 관절 회전을 쿼터니언 4수로 표현하지만 실제 회전 자유도는 3(‖q‖=1 제약). **위치는 과잉좌표 다양체, 속도는 그 접선공간** | W1-M2 |
| **MJX** | MuJoCo를 JAX로 재구현해 `vmap`으로 수천 환경을 GPU에서 병렬 적분하는 백엔드 | 같은 수식, 다른 튜닝. G1 기준 `timestep` 0.002→0.004 · `iterations` 100→5로 **정확도를 처리량과 맞바꿈** | W1-M2 → W3-M1 |
| **position 액추에이터** | $f = k_p(\texttt{ctrl} - q) - k_v \dot q$ 를 내는 MuJoCo 액추에이터. **`ctrl`은 토크가 아니라 목표 관절각[rad]** | 실기 온보드 PD 서보를 시뮬레이터가 이미 모사하고 있는 것. 정책이 내보내는 것은 토크가 아니라 setpoint | W1-M2 → W3-M5 |
| **`dampratio`** | PD 게인을 감쇠비 $\zeta$로 지정하는 MJCF 속성. $k_v = 2\zeta\sqrt{k_p M_{\text{eff}}}$ | G1은 `dampratio="1"`(임계감쇠)이라 **`kv`가 관절마다 다름**(43.01 / 15.85 / 9.43). 역산하면 관절 유효관성이 나옴 | W1-M2 |
| **`armature`** | 관절에 더해지는 반사 관성(rotor inertia). G1은 전 관절 0.01 | 감속기 뒤 모터 로터가 관절에서 보이는 등가 관성. 실기에서는 관절마다 다르므로 **sim2real 갭의 씨앗** | W1-M2 → W3-M5 |
| **`solref` / `solimp`** | 접촉·제약을 무한 강성 대신 스프링-댐퍼로 완화하는 soft-constraint 파라미터 | 상보성 조건(LCP)의 매끄러운 근사. 뻣뻣할수록 정확하지만 `timestep`을 줄여야 함 | W1-M2 |
| **`MUJOCO_GL`** | 렌더링 백엔드 선택 환경변수. `egl`(GPU 오프스크린) / `osmesa`(소프트웨어) / `glfw`(디스플레이 필요) | 클라우드는 `egl`. **`import mujoco` 이전에 설정**해야 적용됨 — 순서를 틀리는 것이 입문 최다 실수 | W1-M2 |
| **`n_substeps`** | 정책 한 스텝 동안 물리를 몇 번 적분하는가. `ctrl_dt / sim_dt` | `G1JoystickFlatTerrain`은 0.02 / 0.002 = **10**. 정책 50 Hz · 물리 500 Hz로 W1-M1 주파수 예산의 L2 대역과 정확히 일치 | W1-M2 → W4-M4 |
| **floating base** | 땅에 고정되지 않고 떠 있는 몸통. 6자유도를 따로 가진다 | 고정 베이스 로봇과 상태 차원이 갈리는 지점. `qpos`를 7칸(위치 3 + 쿼터니언 4), `qvel`을 6칸 먹으면서 액추에이터는 하나도 갖지 않아 **네 주소 체계가 어긋나는 원인** | W1-M2 → W3-M1 |
| **도메인 랜더마이제이션** | 환경마다 질량·마찰·지연을 다르게 뿌려 학습시키는 기법 | 강인제어의 불확실성 집합을 샘플링하는 것. `mjModel`을 "상수"로 두는 규칙을 **환경마다 다른 상수**로 완화해 깬다 | W1-M2 → W3-M5 |
| **비대칭 actor-critic** | 정책과 가치함수에 서로 다른 관측을 주는 학습 관례 | 관측기가 못 보는 상태를 학습 중에만 아는 것으로 치기. `G1JoystickFlatTerrain`은 `state (103,)` / `privileged_state (216,)`이고 **배포되는 것은 103 쪽** | W1-M2 → W3-M1 |
| **특권 정보** | 시뮬에서만 알 수 있고 실기에서는 못 얻는 값 | 지형 높이, 마찰계수, 외력 같은 것. critic에만 주고 actor에는 주지 않는다 | W1-M2 → W3-M1 |
| **headless** | 모니터도 디스플레이 서버도 없는 실행 환경 | 클라우드 인스턴스의 기본 상태. 뷰어를 못 쓰므로 결과는 오프스크린 렌더 → mp4 | W1-M2 |
| **JIT 컴파일** | 첫 호출 때 코드를 기계어로 번역해두고 이후 재사용 | JAX/MJX에서 첫 스텝만 수십 초 걸리고 두 번째부터 빨라지는 이유. 스모크 테스트 시간을 오해하게 만드는 지점 | W1-M2 → W3-M1 |

### W1-M3 — Diffusion 계보: DDPM → DiT

| 용어 | 정의 | 비유 / 메모 | 모듈 |
|---|---|---|---|
| **NFE (Number of Function Evaluations)** | 샘플 하나를 얻는 데 신경망을 forward하는 횟수. 디노이징 스텝 수와 같다 | 이미지에서는 사용자 대기 시간이지만 **로봇에서는 제어 지연 예산 항목.** 이산화 격자 수에 해당 — 250 NFE면 청크가 82스텝·1.64초 개방루프가 된다 | W1-M3 → W1-M4 |
| **$\bar\alpha_t$ (누적 신호 이득)** | $\prod_{s\le t}(1-\beta_s)$. forward 과정에서 $t$까지 살아남은 원신호의 비율 | 공분산 전파 재귀 $P_t = A_tP_{t-1}A_t^\top + Q_t$를 손으로 푼 것. $\mathrm{SNR}(t)=\bar\alpha_t/(1-\bar\alpha_t)$이고 $T=1000$ 선형 스케줄에서 SNR=1 교차점은 $t=259$ | W1-M3 |
| **$\mathcal{L}_{\text{simple}}$** | DDPM의 실제 학습 손실 $\mathbb{E}\|\epsilon-\epsilon_\theta\|^2$. ELBO에서 가중치 $\lambda_t$를 떼어낸 재가중 목적함수 | **LQR 최적 이득을 실기에서 디튠하는 것과 같은 거래** — 하한 자격을 반납하고 지각 품질을 산다. $\lambda_1/\lambda_{1000}\approx49$ | W1-M3 |
| **ancestral sampling** | 매 스텝 노이즈를 다시 주입하며 마르코프 체인을 거꾸로 내려가는 샘플링. 역시간 SDE의 이산화 | Euler-Maruyama에 촘촘한 고정 격자. 확률성 때문에 격자를 마음대로 건너뛸 수 없다 | W1-M3 |
| **DDIM** | 비마르코프 forward 족으로 재정식화해 확률성을 0으로 둔 결정론적 샘플러. 학습된 모델을 그대로 쓴다 | probability flow ODE라 **격자 부분수열을 그대로 쓸 수 있음.** 실측으로 NFE 4~20 구간에서 ancestral 대비 1.2~1.8배 우세, NFE 50 이상은 차이 소멸 | W1-M3 |
| **probability flow ODE** | 확산 과정의 결정론적 등가 ODE | 고차 solver(DPM-Solver 계열) 적용의 문턱이자 스텝 축약의 근거. **NFE 1~2는 샘플러 교체로 뚫리지 않는다** — 그래서 경로 자체를 직선화하는 W1-M4로 간다 | W1-M3 → W1-M4 |
| **patchify** | 텐서를 $p\times p$(액션이면 시간축 $p_t$) 패치로 잘라 토큰열로 만드는 것 | 이미지는 $(I/p)^2$개 토큰, 액션 청크는 $H/p_t$개. **파라미터가 아니라 Gflops가 품질을 결정**한다는 DiT의 중심 주장이 이 노브에서 나온다 | W1-M3 → W2-M4 |
| **adaLN** | LayerNorm의 스케일·시프트를 조건 임베딩에서 회귀해 주입하는 조건부 정규화 | **FiLM 계열.** 조건을 프롬프트 토큰으로 붙이는 in-context 방식보다 강하다(FID 35.24 → 25.21) — 조건이 시퀀스 전체에 균일하게 작용할 때 토큰보다 정규화에 태우는 것이 낫다 | W1-M3 |
| **adaLN-Zero** | adaLN + 잔차 직전의 차원별 스케일 $\alpha$를 추가하고 그 MLP를 0으로 초기화 | $\alpha=0$이면 블록이 항등함수 = **제어의 소프트 스타트.** 게인을 0에서 올리는 순서를 옵티마이저에 위임한 것. 이 하나로 FID 25.21 → 19.47 | W1-M3 |
| **액션 전문가 (action expert)** | VLM 백본과 분리된, 액션 생성 전용 파라미터 집합 | pi0는 300M Gemma 블록(**AdaLN 미사용**), GR00T N1/N1.5는 DiT + AdaLN. "VLA 액션 헤드는 DiT"라는 요약은 **objective와 블록 계보를 구분해** 읽어야 정확하다 | W1-M3 → W2-M4 |
| **ELBO** | Evidence Lower BOund, 증거 하한. 직접 계산할 수 없는 로그가능도 $\log p_\theta(x_0)$ 대신 올려서 최대화하는 하한 | 원 문제를 못 풀 때 풀 수 있는 완화 문제를 대신 푸는 자리. **LLM 응용 실무만으로는 채워지지 않는 생성모델 내부 기제**라 §3.9가 가정 금지로 지정한 용어 | W1-M3 → W1-M5 |
| **score** | 로그 확률밀도의 기울기 $\nabla_x\log p(x)$. 더 그럴듯한 쪽을 가리키는 벡터장 | 포텐셜의 기울기. 샘플링은 이 벡터장을 따르는 적분이 된다. $\epsilon_\theta$는 스케일된 score 추정치 | W1-M3 → W1-M4 |
| **SNR** | Signal-to-Noise Ratio. $\bar\alpha_t/(1-\bar\alpha_t)$로 남은 신호와 쌓인 잡음의 비 | 같은 이름 같은 뜻. 1을 지나는 시점이 국면 전환점이고 $T=1000$ 선형 스케줄에서 $t=259$ | W1-M3 → W1-M4 |
| **사후분포 $q(x_{t-1}\mid x_t,x_0)$** | 시작점 $x_0$를 알 때 한 스텝 되돌린 분포. 가우시안으로 닫힌다 | 칼만 필터의 측정 갱신. 사전분포와 관측을 정밀도 가중으로 융합하는 그 단계 | W1-M3 |
| **재파라미터화** | 같은 대상을 다른 변수로 바꿔 추정하는 것. 평균 $\mu$ 대신 노이즈 $\epsilon$을 맞힌다 | 좌표 변환. 정보량은 같고 수치 조건과 손실 가중만 달라진다 | W1-M3 → W1-M4 |
| **다봉성 (multimodality)** | 같은 조건에서 정답이 여럿인 성질. 시연 데이터가 대표적이다 | 최적해가 여럿인 비볼록 문제. 평균은 어느 해도 아니다. 회귀 대신 생성을 쓰는 이유 | W1-M3 → W2-M2 |

### W1-M4 — Flow Matching & Rectified Flow

| 용어 | 정의 | 비유 / 메모 | 모듈 |
|---|---|---|---|
| **확률 경로 (probability path)** | 노이즈 $p_0=\mathcal{N}(0,I)$에서 데이터 $p_1=q$까지 시간에 따라 이어지는 **분포의 족** $p_t$ | 상태 궤적이 아니라 **분포의 궤적**. 공분산 전파 $P_t$를 분포 전체로 확장한 것에 해당한다. 생성 문제를 "경로를 하나 설계하고 그 경로를 만드는 벡터장을 회귀한다"로 다시 쓰는 것이 이 모듈의 출발점 | W1-M4 |
| **속도장 (velocity field)** | $\frac{d}{dt}\psi_t(x)=u_t(\psi_t(x))$의 우변. 확률 경로를 실제로 밀어내는 시변 벡터장 | **입력 없는 시변 상태방정식 $\dot x=f(x,t)$의 $f$ 그 자체**이고 흐름 $\psi_t$가 천이사상(선형계의 $\Phi(t,0)$). W1-M3의 score와 결정적으로 다른 점은 **주어진 플랜트가 아니라 설계 대상**이라는 것 — 그래서 궤적을 직선으로 만들 수 있다 | W1-M4 |
| **continuity equation** | $\partial_tp_t+\nabla\cdot(p_tu_t)=0$. 속도장이 정해지면 밀도 궤적이 따라 정해진다는 보존식 | 확산항이 없는 Fokker-Planck, 곧 **Liouville 방정식**. 상태방정식이 정해지면 상태분포 전파가 따라 정해지는 구조와 같다. 풀 필요는 없고 "$u_t$가 있으면 $p_t$가 정해진다"는 사실 하나만 쓴다 | W1-M4 |
| **CFM 정리 (Conditional Flow Matching)** | 계산 불가능한 주변 target $u_t(x)=\mathbb{E}[u_t(x\mid x_1)\mid x_t=x]$ 대신 조건부 target을 회귀해도 그래디언트가 같다는 정리. $\nabla_\theta\mathcal{L}_{\text{FM}}=\nabla_\theta\mathcal{L}_{\text{CFM}}$ | **확률근사(Robbins-Monro)에서 참 그래디언트를 편향 없는 추정치로 갈아끼우는 것**과 같은 논리. 대체 대상이 그래디언트가 아니라 기준신호일 뿐이다. 성립의 열쇠는 $u_t$가 **사후평균으로 정의**돼 $p_tu_t$가 조건부의 적분으로 인수분해되는 것. **개별 target은 전부 틀렸지만 그 평균이 정답** — $\mathcal{L}_{\text{simple}}$과 같은 트릭 | W1-M3 → W1-M4 |
| **스케줄 $(\alpha_t,\sigma_t)$ · 가우시안 조건부 경로** | $x_t=\alpha_tx_1+\sigma_tx_0$로 잡는 조건부 경로. target 속도가 $u_t=\dot\alpha_tx_1+\dot\sigma_tx_0$로 닫힌다 | W1-M3의 $\beta_t$ 테이블과 **같은 지위의 설계 상수**(학습되지 않음). $x$에 대한 아핀 벡터장이라 시변 1차 선형계처럼 해가 닫힌다. DDPM은 $\alpha_t^2+\sigma_t^2=1$(VP), RF는 $\alpha_t+\sigma_t=1$(선형) | W1-M4 |
| **Rectified Flow · 직선 경로(CondOT)** | 스케줄을 $\alpha_t=t,\ \sigma_t=1-t$로 잡아 노이즈와 데이터를 직선으로 잇는 특수화. target이 $x_1-x_0$이라 $t$에 무관하고 손실이 한 줄로 붕괴, 스케줄 테이블이 사라진다 | 곡률이 0이면 명시적 Euler의 절단오차 $O(h^2\|\ddot x\|)$도 0 — **한 스텝이 근사가 아니라 정확해.** 무증류 실증권은 NFE 4~10(pi0 **10 integration steps**, $\delta$=0.1 · GR00T N1 **K=4**)이고, 적분 루프에 드는 것은 pi0의 **300M 액션 전문가**뿐 3B 백본은 청크당 1회. **pi0의 세 숫자는 축이 다름** — H=50은 청크 길이, 최대 50 Hz는 하위 소비 주파수 $f_2$, 10 steps가 NFE | W1-M4 → W2-M4 |
| **직선성 지표 $S(Z)$** | $\int_0^1\mathbb{E}\|(Z_1-Z_0)-\dot Z_t\|^2dt$. 0이면 완전한 직선이고 1스텝이 정확 | **NFE 예산을 정하는 것은 적분기가 아니라 경로의 곡률**이고 $S$가 그 곡률의 적분 지표. 조건부 경로가 직선이어도 **보간선이 교차**하면 주변 속도장은 사후평균이라 어느 직선도 아닌 방향이 되고 $S>0$이 된다. 실습 실측(2D two moons) 1-rect **0.9075** | W1-M4 |
| **reflow** | 학습된 flow로 $\hat x_1=\text{ODESolve}(x_0)$를 풀어 $(x_0,\hat x_1)$ 결정론적 짝짓기로 다시 학습하는 절차. $k$회 반복하면 $k$-rectified | **궤적 재계획·경로 평활화.** 초기 계획이 꺾여 있으면 시작–끝점만 남기고 최단 경로를 다시 풀어 매끄럽게 만드는 것. 실습 실측으로 $S(Z)$가 **0.9075 → 1.489e-05**로 내려가지만 **공짜가 아니다** — 누적 학습 스텝 12,000 → 20,000 · 쌍 16,384개를 지불했고, target이 모델 자신의 출력이라 오차를 상속하며 **큰 NFE의 품질을 팔아 작은 NFE의 품질을 산다** | W1-M4 |
| **logit-normal $t$ 샘플링** | $t=\text{sigmoid}(z),\ z\sim\mathcal{N}(m,s^2)$로 중간 $t$에 학습 예산을 몰아주는 SD3(2403.03206)의 선택 | **DDPM이 ELBO의 $\lambda_t$를 버린 자리에 FM은 $t$ 분포를 놓았다.** 암묵적 손실 가중이 눈에 보이는 노브로 올라온 것 — 균등 $t$가 중립이라는 보장은 없다. 재현·파인튜닝에서 가장 먼저 맞춰야 할 하이퍼파라미터 | W1-M4 → W2-M4 |
| **VP↔RF 변환** | 가우시안 경로는 각 시각의 스케일과 SNR로 결정되는데 스케일은 신경망이 흡수하므로, 두 스케줄은 **스케일 재조정 + 시간 재매개화**로 서로 옮겨진다 | $(\sigma,\alpha)$ 평면에서 **VP는 단위원 위의 사분원 호**($\ell_2$ 정규화), **RF는 두 점을 잇는 현**($\ell_1$). SNR=1 지점이 DDPM $t{=}259$ ↔ RF $t{=}0.5000$으로 대응한다. **FM은 diffusion의 대체재가 아니라 일반화** — 다만 균등 $t$ 샘플링에서도 SNR 구간별 예산 배분이 달라(DDPM 앞 25%가 RF 시간의 48%를 덮음) 같은 가족이 같은 모델은 아니다 | W1-M3 → W1-M4 |
| **CNF** | Continuous Normalizing Flow, 연속 정규화 흐름. ODE로 밀도를 밀어 옮기는 가역 생성 모델 | 개념은 FM보다 먼저였으나 학습이 비쌌던 선조. FM은 같은 대상을 시뮬레이션 없이 학습하는 법 | W1-M4 |
| **사후평균 (posterior mean)** | 관측이 주어졌을 때 대상의 조건부 기댓값 | 최소제곱 추정의 최적해이고 칼만 필터가 내놓는 그 값. **CFM 정리의 열쇠** — 개별 target을 맞히라고 시켜도 회귀가 사후평균으로 수렴한다 | W1-M4 |
| **대리 목표 (surrogate target)** | 진짜 목표 대신 회귀시키는, 계산 가능한 값 | 계산 불가능한 기준을 편향 없는 추정치로 갈아끼우는 것. $\mathcal{L}_{\text{simple}}$의 $\epsilon$도 같은 트릭 | W1-M4 |
| **확률근사 (Robbins-Monro)** | 참 그래디언트를 편향 없는 추정치로 바꿔도 같은 곳에 수렴한다는 성질 | 확률적 경사하강이 성립하는 근거 그 자체. FM은 대체 대상을 그래디언트에서 **기준신호**로 옮긴 것 | W1-M4 |
| **짝짓기 (coupling)** | 노이즈 $x_0$과 데이터 $x_1$을 어떤 규칙으로 묶어 학습에 쓰는가 | 어느 시작점을 어느 목표점에 배정할지의 계획 문제. reflow가 손대는 대상 | W1-M4 |
| **증류 (distillation)** | 큰 교사 모델의 출력을 작은 학생 모델이 흉내내게 학습하는 것 | 고차 제어기를 저차로 근사해 실시간에 올리는 것. 1스텝까지 내리면 **다봉성을 뭉갤 위험** | W1-M4 → W2-M2 |
| **MoE** | Mixture of Experts, 전문가 혼합. 입력에 따라 서로 다른 파라미터 묶음을 태우는 구조 | pi0의 액션 전문가가 이 형태로 백본과 가중치를 나눈다. **pi0의 액션 전문가는 DiT가 아니다** | W1-M4 → W2-M4 |
| **proprioception** | 고유수용감각. 관절각과 각속도처럼 로봇이 자기 몸에서 직접 읽는 상태 | 상태 피드백 벡터 그 자체. 외부 센서 없이 얻는 관측 | W1-M4 → W3-M1 |
| **KV 캐시** | 자기회귀 생성에서 앞 토큰의 키와 값을 저장해 재계산을 피하는 장치 | 이전 계산 결과를 남겨 반복 연산을 줄이는 것. **LLM 응용 실무만으로는 채워지지 않는 내부 기제**라 §3.9가 가정 금지로 지정 | W1-M4 → W2-M5 |

### W1-M5 — 잠재공간과 이산화: FSQ ★

| 용어 | 정의 | 비유 / 메모 | 모듈 |
|---|---|---|---|
| **FSQ (Finite Scalar Quantization)** | 인코더 출력을 채널별로 bounding(`tanh`)한 뒤 정수로 반올림해 고정 격자에 매핑하는 이산화. $\hat z = \mathrm{round}(f(z))$, $\|\mathcal{C}\| = \prod L_i$ | **액션의 BPE.** 코드북이 학습되지 않고 격자가 고정 — VQ-VAE의 "개선판"이 아니라 "단순화판" | W1-M5 → W2-M5 |
| **codebook collapse** | VQ 계열에서 코드북 크기를 키울수록 많은 코드워드가 안 쓰이는 현상 | **도달하지 않는 상태공간 영역.** 안 뽑히면 학습 안 되고 학습 안 되면 안 뽑히는 닭-달걀 문제 | W1-M5 |
| **STE (Straight-Through Estimator)** | 미분 불가능한 반올림 연산의 그래디언트를 1로 대체해 통과시키는 트릭. `x + sg(round(x) - x)` | **비선형 요소를 선형화해 루프를 닫는 것.** VQ·FSQ 둘 다 사용 | W1-M5 |
| **implied codebook** | FSQ에서 코드북을 명시적으로 저장하지 않고, 레벨 조합의 곱으로 암묵적으로 정의되는 격자 $\mathcal{C}$ | 학습 파라미터 0개 — DAC의 양자화 레벨이 회로 설계 시점에 고정되는 것과 같음 | W1-M5 |
| **mixed-radix 열거** | 채널별 이산 좌표 $(\hat z_1, \dots, \hat z_d)$를 정수 인덱스 하나로 바꾸는 전단사 매핑 | LLM 토큰 ID로 그대로 쓸 수 있는 이유 | W1-M5 |
| **LDM (Latent Diffusion Model)** | 픽셀 공간이 아니라 VAE 잠재공간에서 확산 과정을 학습 | perceptual compression(VAE)과 semantic compression(확산)의 분리 | W1-M5 → W4-M2 |
| **perceptual / semantic compression** | 전자는 지각적으로 무의미한 고주파 디테일 제거(VAE), 후자는 의미 있는 구조의 분포 학습(확산 모델) | 압축 2단 분리가 비디오 월드모델 백본의 표준 구조 | W1-M5 → W4-M1 |
| **양자화 오차 (이산화 관점)** | 연속 값을 유한 레벨로 반올림할 때 생기는 복원 오차 | 제어의 **DAC 분해능·데드밴드**와 동일 개념. 토큰 레이트를 올리면 줄어들지만 압축률과 상충 | W1-M5 |
| **코드북 사용률** | 검증셋을 인코딩할 때 최소 1회 쓰인 코드워드의 비율 | FSQ 실측 96.8%(\|C\|=1000) vs VQ 21.1% — 논문 Fig 3의 $2^{10}$ 교차를 G1 데이터로 재현 | W1-M5 |
| **토큰 홀드 (zero-order hold)** | 상위가 새 토큰을 내지 않는 구간에서 하위가 마지막 토큰(또는 그 디코딩값)을 유지하는 것 | 제어의 **ZOH**와 동일 개념. action chunking·주파수 접합의 실체 | W1-M5 → W4-M4 |
| **BPE** | Byte Pair Encoding. 자주 붙어 나오는 글자 쌍을 하나로 병합해가며 유한한 토큰 목록을 만드는 절차 | 언어모델이 글자열을 정수 열로 바꾸는 그 앞단. **"FSQ = 액션의 BPE"** 비유의 앵커인데 BPE 자체가 §3.9의 갭 목록에 있으므로 쓸 때 정의부터 | W1-M5 → W2-M5 |
| **teacher forcing** | 학습 중에 모델의 예측 대신 정답 토큰을 다음 입력으로 넣는 방식 | 학습할 때 궤적 발산을 막는 장치. §3.9가 가정 금지로 지정한 LLM 내부 기제 | W1-M5 |
| **stop-gradient (`sg`)** | 순전파는 그대로 두고 역전파만 끊는 연산자 | 특정 경로의 피드백을 의도적으로 차단하는 것. VQ-VAE 손실 3항이 서로를 밀지 않게 하는 장치 | W1-M5 |
| **commitment 손실** | 인코더 출력이 자기 코드워드에서 멀어지지 않게 붙잡는 항 | 반대 방향으로 건 두 번째 적분기. **FSQ에는 이 항이 없다** | W1-M5 |
| **persistent excitation (지속 여자)** | 파라미터가 식별되려면 입력이 충분히 풍부해야 한다는 조건 | codebook collapse의 제어 쪽 앵커. **여자가 부족하면 그 모드는 끝내 수렴하지 않는다** | W1-M5 |
| **per-dim binning** | 액션 벡터의 각 차원을 따로 구간으로 잘라 차원마다 토큰 하나씩 내는 방식 | 채널마다 별도 양자화기를 다는 것. 채널 간 상관을 못 담는 것이 FSQ와 갈리는 지점 | W1-M5 → W2-M3 |
| **데드밴드 (deadband)** | 입력이 변해도 출력이 반응하지 않는 구간 | 격자 간격보다 작은 보정을 낼 수 없어 생기는 무반응 영역. 이산화가 지불하는 대가 | W1-M5 |
| **바운딩 함수 $f$** | 인코더 출력을 반올림 격자 범위 안으로 눌러 넣는 함수 | 액추에이터 포화를 모델에 미리 넣는 것 | W1-M5 |
| **명령 공백** | 상위가 다음 명령을 못 낸 사이 하위에게 먹일 것이 없어지는 구간 | 캐스케이드 구조에서 바깥 루프가 늦을 때 생기는 문제 | W1-M5 → W4-M4 |
| **universal token space** | 여러 상위 입력원을 하나의 정책에 물리기 위한 공통 토큰 공간 | SONIC의 핵심 장치. VLA와 텔레옵과 게임패드 플래너를 한 정책에 연결한다 | W1-M5 → W3-M4 |

## W2

### W2-M1 — 모방학습 기초 + ACT

| 용어 | 정의 | 비유 / 메모 | 모듈 |
|---|---|---|---|
| **Behavior Cloning (BC)** | 전문가 시연 $\mathcal{D} = \{(o_t, a_t)\}$로 정책을 지도학습하는 것. $\theta^\star = \arg\min_\theta \mathbb{E}_{(o,a)\sim\mathcal{D}}[\ell(\pi_\theta(o), a)]$ — 보상 함수도 환경 상호작용도 필요 없다 | **시스템 동정의 방향이 반대.** 동정은 플랜트를 맞추고 BC는 제어기를 맞춘다 | W2-M1 → W2-M2 |
| **compounding error** | BC 정책의 작은 오차가 상태를 학습 분포 밖으로 밀고, 밀린 상태에서 오차가 더 커지는 양의 피드백. 최악 비용 상한이 지평 $T$에 대해 $O(\epsilon T^2)$ | **개루프 dead-reckoning의 적분 오차 누적.** $O(\epsilon T)$가 한 번 적분이면 $O(\epsilon T^2)$는 두 번 적분 스케일 | W2-M1 → W2-M2 |
| **covariate shift (로봇 문맥)** | 학습 데이터 분포와 실행 시 마주치는 분포의 불일치 | 로봇에서 특별한 이유는 그 shift를 만드는 원인이 외부 요인이 아니라 **학습된 모델 자신**이라는 점 — 정적 문제가 아니라 동적 되먹임 | W2-M1 |
| **DAgger (Dataset Aggregation)** | 정책 자신이 방문한 상태에 전문가가 정답 액션을 다시 라벨링해 데이터셋에 합치고 재학습하는 반복 절차(arXiv:1011.0686). 상한을 $O(\epsilon T^2)$에서 $O(\epsilon T)$로 내린다 | **이론적으로 옳지만 로봇에서 비싸다** — 사람 라벨링 노동, 위험 자세 재현, 하드웨어 마모. LeRobot 롤아웃에 `--strategy.type=dagger`로 실재 | W2-M1 |
| **action chunking** | 정책이 한 스텝이 아니라 미래 $k$스텝의 액션을 한 번에 예측하는 것. $\pi_\theta: o_t \mapsto \hat a_{t:t+k-1}$. 결정 횟수를 $T$에서 $T/k$로 줄여 상한을 $O(\epsilon_k T^2/k)$로 내리지만 $\epsilon_k$가 $k$와 함께 커져 최적 $k$가 중간에 있다 | **MPC의 예측 지평 $N$ 선택 문제 그 자체.** W1-M1에서는 지연을 감추는 버퍼로 만났고 여기서는 compounding error 억제 장치로 다시 만난다 | W1-M1 → W2-M1 → W2-M2 → W2-M4 |
| **`chunk_size` vs `n_action_steps`** | 전자는 한 번의 추론으로 **예측하는** 스텝 수(= 디코더 쿼리 개수), 후자는 그중 실제로 환경에서 **실행하는** 스텝 수. LeRobot ACT 기본값은 둘 다 100이라 청크를 끝까지 개방루프로 실행한다 | **receding horizon은 ACT의 기본값이 아니라 옵션이다.** 이 두 숫자의 관계가 L3 인터페이스 설계 변수 | W2-M1 → W2-M2 → W4-M4 |
| **temporal ensembling** | 매 스텝 재추론해 같은 시각에 대한 여러 예측을 지수 가중 평균하는 것. $w_i = \exp(-mi)$이고 LeRobot 규약상 $w_0$가 **가장 오래된** 예측(`ACTTemporalEnsembler` docstring: "where w₀ is the oldest action"). `temporal_ensemble_coeff` 기본값은 `None`(미사용), 권장 0.01. 켜면 `n_action_steps=1`이 강제돼 추론 호출이 100배 | **EWMA 필터이자 여러 예측기의 신뢰도 가중 융합.** 저역통과라 매끄러워지고 대가로 위상 지연 | W2-M1 |
| **CVAE latent $z$ (ACT)** | 학습 시 인코더 $q_\phi(z \mid a_{t:t+k}, o_t)$가 시연자 스타일 변동을 흡수하는 잠재변수. `latent_dim=32`. **추론 시에는 `torch.zeros`로 0 고정**이라 배포 모델은 결정론적이다 | **실행 시 모드를 골라주는 장치가 아니라 학습 시 회귀가 평균으로 뭉개지는 것을 막는 정규화 장치.** 실행 시점의 다봉성은 Diffusion Policy 담당 | W2-M1 → W2-M2 |
| **`kl_weight` = $\beta$** | ACT loss `loss = l1_loss + mean_kld * kl_weight`에서 KL 항 가중이고 기본값 **10.0**. $\beta$-VAE의 $\beta$와 같은 자리 — 크게 잡으면 $z$가 담는 정보량이 줄어 추론 시 $z=0$과의 괴리가 작아진다 | **LQR의 입력 가중 $R$을 키워 자유도를 눌러 강인성을 사는 것** — 여기서는 재구성 정확도를 팔아 학습·배포 일관성을 산다 | W2-M1 |
| **디코더 쿼리 (DETR식)** | ACT 디코더가 받는 학습된 쿼리 임베딩 `[100, 512]`. **쿼리 개수 = `chunk_size`**이고 각 쿼리가 청크의 한 타임스텝을 담당한다. 자기회귀가 아니라 한 번의 forward로 100스텝이 병렬 출력된다 | LLM 배경이면 헷갈리는 지점 — **청크는 토큰을 순차 생성하는 것이 아니다** | W2-M1 → W2-M4 |
