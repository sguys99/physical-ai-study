### 5.3 여기서 볼 것 ① — 항등을 만드는 것은 $\alpha$ 하나

세 줄을 따로 보면 안 되고 **함께** 봐야 합니다.

| 초기화 | $\gamma,\beta$ | $\alpha$ | 결과 |
|---|---|---|---|
| adaLN-Zero | 0 | 0 | **항등** |
| 랜덤 | 랜덤 | 랜덤 | 항등 아님 |
| **랜덤인데 $\alpha$만 0** | **랜덤** | **0** | **항등** |

> 🔴 세 번째 줄이 결정적입니다. $\gamma,\beta$가 아무리 흔들려도 **잔차 게이트 $\alpha$가 0이면 그 가지의 출력이 통째로 0**이 되고 블록은 $h_{\text{out}} = h_{\text{in}} + 0 + 0$이 됩니다.
> lesson §6.2 표에서 adaLN(FID 25.21) → adaLN-Zero(19.47)의 차이가 **이 $\alpha$ 하나**이고, DiT 원문 문장("this initializes the full DiT block as the identity function")이 `torch.allclose(..., atol=0)`으로 확인됩니다.

**제어 대응**: 게인을 0에서 출발시키는 **소프트 스타트**입니다. 다단 캐스케이드를 전 이득으로 한꺼번에 닫으면 초기 과도응답이 발산할 수 있어 안쪽부터 순차적으로 닫는데, adaLN-Zero는 그 순서를 옵티마이저에 위임한 것입니다. 28층을 통과해도 초기 신호가 변형되지 않으니 그래디언트가 깊이에 따라 폭주·소멸하지 않습니다.

**worksheet ③에 답할 것**: "항등을 만드는 것이 $\gamma\cdot\beta$가 아니라 $\alpha$인 이유"를 한 문단으로.

     행이 우리 헤드인지가 §8.3 표의 NFE 상한을 통째로 바꿉니다. 실측값은 §10 팀 질문 2번.

### 6.2 워크시트에 무엇이 그려져 있는가

### 6.3 ★ 채점 체크리스트 (worksheet ④에 그대로 있습니다)

채운 뒤 [`../lesson.md`](../lesson.md) §6.3과 대조하세요. **아래 3군이 이 문항의 채점 기준입니다.**

**A. 6개 변조 지점 — $\gamma_1,\beta_1,\alpha_1,\gamma_2,\beta_2,\alpha_2$가 각각 어디에 곱해지는가**

- [ ] $\gamma_1,\beta_1$ — **첫 LayerNorm 직후**, self-attention **앞**. `⊙(1+γ₁) ⊕ β₁`
- [ ] $\alpha_1$ — **self-attention 출력 뒤, 첫 잔차 덧셈 직전**
- [ ] $\gamma_2,\beta_2$ — **두 번째 LayerNorm 직후**, MLP **앞**
- [ ] $\alpha_2$ — **MLP 출력 뒤, 두 번째 잔차 덧셈 직전**
- [ ] 여섯 개 전부 `[B, 1, d]`이고 **토큰 축($T$)으로 broadcast**된다
- [ ] LayerNorm은 **`elementwise_affine=False`** — 학습 스케일·시프트를 $\gamma,\beta$가 **대체**하기 때문

**B. 조건 경로**

- [ ] $c = \mathrm{Emb}(t) + \mathrm{Emb}(y)$ — **두 임베딩 벡터의 합**, `[B, d]`
- [ ] 경로가 **`SiLU → Linear(d → 6d)`** 이고 출력을 **6등분(chunk 6)** 한다
- [ ] 이미지 DiT에서 $y$는 **클래스 라벨**, 액션 헤드에서는 $t$만 adaLN에 태우고 관측은 cross-attention으로 간다(§7.1)

**C. zero-init 위치와 논리**

- [ ] **0으로 초기화하는 것은 `Linear(d → 6d)` 하나**다 — 블록 본체의 가중치가 아니다
- [ ] 그래서 초기에 $\gamma=\beta=\alpha=0$이고, **$\alpha=0$ 때문에** 두 잔차 가지가 닫혀 $h_{\text{out}}=h_{\text{in}}$
- [ ] 항등을 만드는 것은 **$\alpha$ 하나** — $\gamma,\beta$가 아니다(Step 5의 세 번째 줄)
- [ ] 28층을 통과해도 초기 신호가 변형되지 않아 그래디언트가 폭주·소멸하지 않는다
- [ ] 제어 대응: **소프트 스타트**. 게인을 0에서 열어가는 절차를 옵티마이저에 위임한 것

## Step 7 — ★★ §5.2 표를 자기 숫자로 재계산 (35분)

> 🔴 **이 랩의 본체 ②입니다.** lesson §13이 지정한 두 산출물 중 나머지 하나 — **"§5.2 표를 자기 손으로 다시 계산한 것"** 입니다.
> [`../practice/README.md`](../practice/README.md) §6의 **직접 해볼 과제 B**와 같은 과제이고, 여기서 정식으로 합니다.

### 7.1 산수의 뼈대 — 세 줄입니다

lesson §5.2의 가정: $f_2=50$ Hz, $\tau_{\text{comm}}=20$ ms, VLM 백본 $\tau_{\text{VLM}}=60$ ms, $T_{\text{replan}}=\tau_{\text{infer}}$.

$$
\tau_{\text{infer}} = \tau_{\text{VLM}} + \text{NFE} \times t_{\text{NFE}}
$$

$$
\text{최악 반응 지연} = 2\,\tau_{\text{infer}} + \tau_{\text{comm}}
$$

$$
H_{\text{chunk}} = \left\lceil f_2 \times \text{최악 반응 지연} \right\rceil
$$

**검산 — lesson §5.2 표의 NFE=250 행이 나오는지 확인하세요.**

$$
\tau_{\text{infer}} = 60 + 250\times3 = 810\ \text{ms}
\quad\Rightarrow\quad
2(810)+20 = 1{,}640\ \text{ms}
\quad\Rightarrow\quad
H = \lceil 50\times1.640\rceil = 82
$$

lesson 표와 일치합니다(82 스텝 · 1,640 ms). **이 검산이 되면 나머지는 $t_{\text{NFE}}$만 바꿔 넣는 일입니다.**

> 💡 지연을 NFE의 함수로 정리하면 한 줄이 됩니다: $\;\text{지연}(\text{ms}) = 2\tau_{\text{VLM}} + \tau_{\text{comm}} + 2\,\text{NFE}\cdot t_{\text{NFE}} = 140 + 2\,\text{NFE}\cdot t_{\text{NFE}}$.
> 여기서 **"지연이 200 ms를 넘지 않는 NFE 상한"** 이 바로 나옵니다: $\text{NFE} \le 30 / t_{\text{NFE}}$.

### 7.2 할 일 ① — $t_{\text{NFE}}$를 자기 실측에서 고르기

Step 5의 벤치 4행 중 **어느 행이 우리 헤드일 것 같습니까?** 정답이 없는 판단입니다.

| 후보 | $t_{\text{NFE}}$ (자기 기기 실측) | 고르는 근거 |
|---|---|---|
| d=128, 1.3M | | 이 실습 규모. 실제 VLA 헤드로는 너무 작습니다 |
| d=256, 7.4M | | |
| d=512, 57.7M | | |
| **d=1152, 673.7M** | | **DiT-XL 구성.** pi0의 액션 전문가가 300M이므로 이 근방이 현실적 상한 |

> ⚠️ **벤치 값을 그대로 쓰면 안 되는 이유도 함께 적으세요**(practice README §8): 토큰 16개·배치 1·**조건 토큰 없음**의 값입니다. 실제 헤드는 멀티뷰 이미지 패치와 언어 토큰에 cross-attention을 겁니다.
> **그래서 이 재계산은 "정답"이 아니라 "하한"입니다.** 실제로는 더 느립니다.

### 7.3 할 일 ② — §5.2 표를 통째로 다시 채우기

worksheet ⑤의 표를 자기 $t_{\text{NFE}}$로 채웁니다. **참고로 lesson의 3 ms 가정과 DiT-XL GPU 실측(14 ms)을 나란히 놓으면 이렇게 벌어집니다.**

| NFE | $H_{\text{chunk}}$ @ 3 ms | 지연 @ 3 ms | $H_{\text{chunk}}$ @ 14 ms | 지연 @ 14 ms |
|---|---|---|---|---|
| 1 | 8 | 160 ms | 9 | 180 ms |
| 10 | 10 | 200 ms | **21** | **420 ms** |
| 20 | — | — | **35** | **700 ms** |
| 50 | 22 | 440 ms | **72** | **1,440 ms** |
| 250 | 82 | 1,640 ms | **352** | **7,040 ms** |

**직접 검산해 보세요.** NFE=10, $t_{\text{NFE}}$=14 ms → $\tau_{\text{infer}}=60+140=200$ ms → 지연 $=2(200)+20=420$ ms → $H=\lceil 50\times0.420\rceil=21$. ✅

### 7.4 할 일 ③ — §8.3의 자리별 NFE 상한 다시 계산

| 자리 | 주기 예산 | 헤드에 남는 시간 | 상한 @ 3 ms *(lesson)* | 상한 @ 자기 값 |
|---|---|---|---|---|
| L2 안에 직접 · 50 Hz | 20 ms | 20 ms | 6 NFE | |
| L2 안에 직접 · 500 Hz | 2 ms | 2 ms | **0 NFE** | |
| **L4 청크 생성 · 5 Hz** | 200 ms | **140 ms** | **46 NFE** | |
| L4 청크 생성 · 10 Hz | 100 ms | 40 ms | 13 NFE | |

**집필 환경 실측으로 채우면 L4 5 Hz 자리가 이렇게 바뀝니다.**

| $t_{\text{NFE}}$ | 출처 | L4 5 Hz 자리 NFE 상한 |
|---|---|---|
| 3 ms | **lesson §8.3 가정** | **46** |
| 10 ms | lesson §8.3 보수적 가정 | 14 |

> 🔴 **가정 하나(3 ms → 14 ms)가 NFE 상한을 46에서 10으로 잘라냅니다.** 이것이 lesson §8.4 ③("실측 NFE와 forward 시간")이 **미확인 항목**인 이유이고, §10 팀 질문 2번이 **세 숫자를 한 번에 묻는** 이유입니다.
